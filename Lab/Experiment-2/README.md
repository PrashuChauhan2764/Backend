# Experiment 2: CSS Demonstration

Create a web page demonstrating Inline, Internal, and External CSS, CSS selectors, Flexbox, Grid, animations, transitions, and responsive design.

## Files

- `index-external.html` — External CSS example (provided earlier).
- `index-internal.html` — Internal CSS example (provided earlier).
- `index-inline.html` — Inline CSS demonstration.
- `index-selectors.html` — Major CSS selector types.
- `index-layout.html` — Flexbox and CSS Grid layouts.
- `index-animations.html` — CSS transitions, keyframe animations, and timing functions.
- `styles.css` — External stylesheet used by `index-external.html`.

## Run

Open any HTML file in a browser. For the external CSS example, keep `index-external.html` and `styles.css` in the same folder. VS Code Live Server can also be used.
